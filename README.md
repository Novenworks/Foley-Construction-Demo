# Foley Construction — speculative website redesign

This is a **Novenworks speculative concept** for [Foley Construction](https://www.foleyconstruction.com/), a family-owned design-build remodeling company in Fullerton, California.

Foley Construction is **not** a Novenworks client. This demo was not commissioned. Business name, marks, and project photography remain the property of their owners and are used here only to show a clearer presentation of an existing company.

## What it is

A production-buildable TanStack Start + React + Tailwind site that:

- Puts real Foley kitchen and family-room photography in front of a homeowner
- Surfaces CSLB license #518685 (Class B, current and active)
- Makes `(714) 879-4618` a working call path
- Keeps copy inside first-party + official facts

## Local development

This workspace is configured for the Grok App Builder preview (`npm run dev` on port 8080). From the project root:

```bash
npm install
npm run dev
```

```bash
npm run build
npm run typecheck
```

## Stack

TanStack Start, React 19, TypeScript, Tailwind CSS v4, Radix/shadcn-style primitives.
